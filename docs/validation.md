# 初期版の検証（2026-11-22）

## 実施済み

- Node.js 24 / Viteによる本番ビルド成功。
- 拍数計算のユニットテスト3件成功（複数声部、和音・装飾音、不正な音価）。
- 認識エンジンと3モデルのSHA-256検証成功。
- ブラウザーでサンプルを認識し、4パート・165個の音高付き音符を表示。
- サンプルMIDIを保存し、MThd/MTrk構造、5トラック、163発音イベントを確認。タイなどにより譜面の音符数と発音数は一致しない。
- 公開GitHub Pages上でもサンプル認識、楽譜表示、音高編集、取り消しを確認。

## 利用者提供スキャンPDF

原稿は12ページ。1ページ目は表紙。PDF内2ページ目をローカルで切り出し、PDF入力として検証。私有PDF・派生データは公開しない。

- 自動モードでは21段を順次連結して1パートにしてしまう問題を発見。
- 「大編成スコア（1ページに1段）」モードを追加し、同時進行する21パートに分離。
- 401音符、テンポ108を取得。MusicXMLとMIDIの保存成功。
- 出力MusicXMLの20パートは4小節、末尾1パートは3小節。末尾パートは欠落の確認が必要。
- 出力MIDIは23トラック、4,112バイト。ヘッダーを確認。
- P20の第2〜4小節に拍数の不一致候補。小節数不足も確認候補として表示するよう追加。

これは動作・構造の確認であり、正解データとの音高・リズム精度測定ではない。原稿全12ページの認識精度、移調・打楽器の正しさは未検証。

## 既知のビルド警告

Verovioが大きいバンドルを生成すること、実行環境に応じたnode:moduleの外部化、静的ホスト用Service Workerの非moduleスクリプト、認識ワーカーの相対アセットURLについてViteの警告が出る。現時点では本番のサンプル動作を確認済み。初回ダウンロード容量の削減は今後の改善対象。
